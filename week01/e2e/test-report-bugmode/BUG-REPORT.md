## BUG-01 · คูปอง PAW10 ลดผิด (P1 สูง)
- **ขั้นตอนทำซ้ำ:** ใส่ "แมวโต สูตรไก่ 3 kg" (฿799) ในตะกร้า → ใส่คูปอง PAW10
- **ผลที่คาดหวัง:** ลด ฿79 → ยอดชำระ ฿770
- **ผลจริง:** ส่วนลด PAW10 **-฿7** → ค่าจัดส่ง ฿50 → ยอดชำระ **฿842**
- **หลักฐาน:** [gifs/TC-CPN-01.gif](gifs/TC-CPN-01.gif)
- **ความรุนแรง:** สูง (คำนวณเงินผิด)

## BUG-02 · เบอร์โทร 9 หลักไม่ขึ้น error (P1 สูง)
- **ขั้นตอนทำซ้ำ:** login → ใส่สินค้าในตะกร้า → หน้า checkout กรอกเบอร์โทร 9 หลัก (`081234567`) → ยืนยันสั่งซื้อ
- **ผลที่คาดหวัง:** error เบอร์โทร (ต้องมี 10 หลัก)
- **ผลจริง:** ไม่พบข้อความ error เบอร์โทร (test หาข้อความที่มี "เบอร์โทร ... 10 หลัก" ไม่เจอ)
- **หลักฐาน:** [gifs/TC-CHK-02.gif](gifs/TC-CHK-02.gif)
- **ความรุนแรง:** สูง (ข้อมูลจัดส่งผิดผ่านการตรวจ)

## BUG-03 · ลบรายการโปรดแล้วตัวเลขหัวใจไม่ลด (P2 ปานกลาง)
- **ขั้นตอนทำซ้ำ:** กดหัวใจ 2 ชิ้น (ตัวเลข 2) → ลบ 1 ชิ้นในหน้ารายการโปรด
- **ผลที่คาดหวัง:** ตัวเลขลดเป็น 1 ทันที
- **ผลจริง:** ตัวเลข `wishlist-count` ยังเป็น **2**
- **หลักฐาน:** [gifs/TC-WISH-02.gif](gifs/TC-WISH-02.gif)
- **ความรุนแรง:** ปานกลาง

## BUG-04 · ย้ายไปตะกร้าแล้วตัวเลขหัวใจไม่ลด (P2 ปานกลาง)
- **ขั้นตอนทำซ้ำ:** มีรายการโปรด 1 ชิ้น → กด "ย้ายไปตะกร้า"
- **ผลที่คาดหวัง:** หายจากรายการโปรด ตัวเลขหัวใจเป็น 0
- **ผลจริง:** ตัวเลข `wishlist-count` ยังเป็น **1**
- **หลักฐาน:** [gifs/TC-WISH-03.gif](gifs/TC-WISH-03.gif)
- **ความรุนแรง:** ปานกลาง (น่าจะต้นเหตุเดียวกับ BUG-03 เพราะอาการเหมือนกัน แต่ยังไม่ยืนยัน)

## BUG-05 · ฟอร์มสมัครเปล่า ช่องยืนยันรหัสผ่านไม่ขึ้น error (P2 ปานกลาง)
- **ขั้นตอนทำซ้ำ:** หน้าสมัครสมาชิก → กดส่งโดยไม่กรอกอะไร
- **ผลที่คาดหวัง:** error ทุกช่อง
- **ผลจริง:** ชื่อ อีเมล รหัสผ่าน เงื่อนไข ขึ้น error แต่ `error-confirm` ไม่มี
- **หลักฐาน:** [gifs/TC-AUTH-02.gif](gifs/TC-AUTH-02.gif)
- **หมายเหตุ:** บั๊กเดิม ไม่เกี่ยวกับ BUG_MODE
