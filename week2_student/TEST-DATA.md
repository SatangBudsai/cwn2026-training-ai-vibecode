## 11. ไฟล์ทดสอบอัปโหลด

ตัวตรวจไฟล์ดูที่เนื้อไฟล์ (magic bytes) ดังนั้นไฟล์ทดสอบสร้างด้วยหัวไฟล์จริง + ขยายขนาดให้ตรงไบต์

| ไฟล์ | ชนิดที่แท้จริง | ขนาด (ไบต์) | ผลที่คาดหวัง |
|---|---|---|---|
| `ok-id.pdf` `id-card.pdf` `map.pdf` `plan.pdf` `deed.pdf` | PDF | 1,024 | รับ |
| `real.jpg` · `real.png` | JPEG · PNG | 1,024 | รับ (ช่องบัตรประชาชน/ภาพสถานที่/แผนที่) |
| `plan-as-jpg.jpg` | JPEG | 1,024 | ช่องแบบแปลน SV-03 → "แบบแปลนต้องเป็นไฟล์ PDF เท่านั้น" |
| `size-5242879.pdf` | PDF | **5,242,879** | รับ |
| `size-5242880.pdf` | PDF | **5,242,880** | รับ (ขอบ ≤) |
| `size-5242881.pdf` | PDF | **5,242,881** | ปฏิเสธ "ไฟล์ใหญ่เกิน 5 MB" |
| `fake-text.pdf` · `fake-text.jpg` | ข้อความ `hello` | 5 | ปฏิเสธ "รองรับเฉพาะไฟล์ PDF, JPG, PNG" |
| `exe-as.png` | หัวไฟล์ `MZ` (exe) | 1,024 | ปฏิเสธ (ชนิดเดียวกัน) |
| `notes.txt` | ข้อความ | 5 | ปฏิเสธ |
| `multi-1.pdf` ถึง `multi-6.pdf` | PDF | 1,024 | ใช้ทดสอบจำนวน: รวมไฟล์ที่แนบแล้ว 5 → รับ · ไฟล์ที่ 6 → "แนบได้สูงสุด 5 ไฟล์ต่อคำขอ" |

สร้างไฟล์ (วางใน `testfiles/` ของโปรเจกต์ test แล้วรัน `python make_testfiles.py`):

```python
# make_testfiles.py
import os, struct, zlib
os.makedirs("testfiles", exist_ok=True)

def pdf(n):                      # PDF จริงขนาด n ไบต์ (หัว %PDF + เติมช่องว่างแล้วปิดด้วย %%EOF)
    head = b"%PDF-1.4\n1 0 obj<</Type/Catalog>>endobj\n"
    tail = b"\ntrailer<</Root 1 0 R>>\n%%EOF\n"
    pad = n - len(head) - len(tail)
    assert pad >= 0
    return head + b" " * pad + tail

def png(n):                      # PNG จริง 1x1 + เติม chunk ข้อความให้ครบขนาด
    def chunk(t, d): return struct.pack(">I", len(d)) + t + d + struct.pack(">I", zlib.crc32(t + d) & 0xffffffff)
    base = b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", struct.pack(">IIBBBBB", 1, 1, 8, 2, 0, 0, 0)) \
         + chunk(b"IDAT", zlib.compress(b"\x00\xff\x00\x00")) + chunk(b"IEND", b"")
    pad = n - len(base) - 12     # chunk tEXt: 12 ไบต์ overhead
    return base[:-12] + chunk(b"tEXt", b"k\x00" + b"x" * (pad - 2)) + base[-12:]

def jpg(n):                      # JPEG จริงแบบย่อ: SOI + APP0 + เติม COM + EOI
    soi = b"\xff\xd8"; app0 = b"\xff\xe0\x00\x10JFIF\x00\x01\x01\x00\x00\x01\x00\x01\x00\x00"
    pad = n - len(soi) - len(app0) - 2 - 4
    return soi + app0 + b"\xff\xfe" + struct.pack(">H", pad + 2) + b"x" * pad + b"\xff\xd9"

def w(name, data):
    open(os.path.join("testfiles", name), "wb").write(data)

for n in ["ok-id.pdf", "id-card.pdf", "map.pdf", "plan.pdf", "deed.pdf"] + [f"multi-{i}.pdf" for i in range(1, 7)]:
    w(n, pdf(1024))
w("real.jpg", jpg(1024)); w("real.png", png(1024)); w("plan-as-jpg.jpg", jpg(1024))
for n in (5242879, 5242880, 5242881): w(f"size-{n}.pdf", pdf(n))
w("fake-text.pdf", b"hello"); w("fake-text.jpg", b"hello"); w("notes.txt", b"hello")
w("exe-as.png", b"MZ" + b"\x00" * 1022)

for f in sorted(os.listdir("testfiles")):
    print(f, os.path.getsize(os.path.join("testfiles", f)))
```

ตรวจหลังสร้าง: `size-5242879.pdf` = 5,242,879 · `size-5242880.pdf` = 5,242,880 · `size-5242881.pdf` = 5,242,881 ไบต์ตรงตัว (5 MB = 5 × 1,048,576)

ไฟล์ปลอมอีกแบบ: ส่ง `fake-text.pdf` ด้วย `Content-Type: application/pdf` (ใน Playwright `setInputFiles({name:'fake-text.pdf', mimeType:'application/pdf', buffer})`) ต้องถูกปฏิเสธเช่นกัน (A-49)
