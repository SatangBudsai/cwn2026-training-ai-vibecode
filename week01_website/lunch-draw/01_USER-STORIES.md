# 📖 User Stories — ข้าวไหนดี (lunch-draw)

เว็บสุ่มร้านข้าวกลางวันของทีมที่ **อาคารจันวาณิชย์ สีลม** สุ่มจากร้านในรัศมี 1 กม. (237 ร้านจาก OpenStreetMap) โดยทีมช่วยกันปรับโอกาสของแต่ละร้านได้

> **ที่มาของเอกสาร:** ไม่มีบันทึกสัมภาษณ์ตัวจริงเหลืออยู่ เอกสารนี้จึงเรียบเรียงย้อนหลังจากระบบที่สร้างเสร็จแล้ว (ซอร์สโค้ดที่กู้จาก source map ใน `.next/`) และจาก `e2e/test-cases.json` (84 test case) ตัวเลขทุกตัวตรงกับโค้ดใน `src/lib/odds.ts` ถ้าคำตอบของทีมต่างจากนี้ ให้แก้ที่นี่ก่อน แล้วค่อยแก้เอกสารขั้นถัดไป

## 4. Stories

รูปแบบ: **ในฐานะ** … **ฉันต้องการ** … **เพื่อ** …
เงื่อนไขการยอมรับ (Acceptance Criteria) เขียนแบบ Given / When / Then ส่วนคอลัมน์ "ทดสอบโดย" อ้างถึง test case ในรายงาน e2e

### Epic A — สุ่มร้าน

#### US-01 ดูโอกาสของแต่ละร้าน · Must
**ในฐานะ** คนหิว **ฉันต้องการ** เห็นว่าแต่ละร้านมีโอกาสถูกสุ่มกี่เปอร์เซ็นต์ **เพื่อ** เชื่อว่าการสุ่มยุติธรรม

- **Given** ข้อมูลเริ่มต้น 237 ร้าน ยังไม่มีใครโหวต **When** เปิดหน้าแรก **Then** เห็นหัวข้อ "วันนี้กินร้านไหน" จำนวนร้าน 237 ประเภทอาหาร 16 แนว และกระดานแสดง 15 อันดับแรก
- **Given** ยังไม่มีโหวตและไม่มีร้านที่กินแล้ว **Then** ทุกร้านมีโอกาสเท่ากัน 1/237 = 0.4%
- **When** กด "แสดงทั้งหมด 237 ร้าน" **Then** กระดานแสดงทุกร้าน และกด "แสดงเฉพาะ 15 อันดับแรก" เพื่อย่อกลับได้
- ร้านเรียงจากโอกาสมากไปน้อย ถ้าเท่ากันเรียงตามเลขร้าน
- แต่ละแถวแสดงชื่อร้าน (หรือชื่อเล่น) ระยะเดิน ประเภทอาหาร และตัวคูณที่มีผล

ทดสอบโดย: TC-HOME-01, TC-HOME-02, TC-HOME-03

#### US-02 สุ่มร้าน · Must
**ในฐานะ** คนหิว **ฉันต้องการ** กดปุ่มเดียวแล้วได้ร้าน พร้อมวิธีเดินไป **เพื่อ** ไม่ต้องเถียงกันอีก

- **When** กด "สุ่มร้าน" **Then** มีแอนิเมชันสั้น ๆ แล้วการ์ดผลแสดงชื่อร้าน ระยะเดิน (ม.) เวลาเดิน (นาที) และโอกาสที่ร้านนี้มีตอนสุ่ม
- การ์ดผลมีลิงก์ Google Maps ที่ตรงพิกัดร้าน และลิงก์นำทางจากออฟฟิศแบบ **เดิน**
- หลังได้ผล ปุ่มเปลี่ยนเป็น "สุ่มใหม่"
- การสุ่มทำที่ server เสมอ และใช้ตัวสุ่มที่ปลอดภัย (crypto) ร้านที่ถูกปิดหรือไม่ผ่านตัวกรองต้องไม่ถูกสุ่ม
- **Given** ไม่มีร้านเหลือหลังกรอง **Then** ปุ่มสุ่มร้านกดไม่ได้ และ API ตอบ 409 "ไม่มีร้านให้สุ่ม…"

ทดสอบโดย: TC-DRAW-01, TC-DRAW-02, TC-DRAW-03, TC-API-04

#### US-03 โหวตประเภทอาหาร · Must
**ในฐานะ** คนหิว **ฉันต้องการ** บอกว่าวันนี้อยากหรือไม่อยากกินแนวไหน **เพื่อ** ให้ร้านแนวนั้นมีโอกาสมากหรือน้อยลง โดยไม่ตัดร้านทิ้ง

- แต่ละประเภทมีสวิตช์ 3 ช่อง **ไม่เห็นด้วย | ปกติ | เห็นด้วย** (= −1, 0, +1) เลือกได้ทีละช่อง ค่าเริ่มต้นคือ ปกติ
- ตัวคูณของแนว = 1 + 0.5 × คะแนนสุทธิ (ต่ำสุด ×0.1) เช่น +1 = ×1.5, −1 = ×0.5, +2 = ×2.0
- **When** เลือก เห็นด้วย ที่ "ก๋วยเตี๋ยว / เมนูเส้น" **Then** สวิตช์อยู่ที่ เห็นด้วย และแสดง ×1.5 ร้านอันดับ 1 เป็นร้านก๋วยเตี๋ยว
- **When** เลือก ปกติ **Then** ยกเลิกโหวต กลับเป็น 0 และไม่แสดงตัวคูณ
- ร้านที่มีหลายแนว ใช้ตัวคูณของ **แนวที่ดีที่สุด** (เช่น เส้น −1 ส้มตำ +1 → ร้านที่เป็นทั้งสองแนวได้ ×1.5)
- โหวตเป็นแบบร่างก่อน: กระดานยังไม่เรียงใหม่จนกว่าจะกด **บันทึกโหวต** ในแถบด้านล่างจอ (กด ยกเลิก เพื่อทิ้งร่าง) หน้าจอจึงไม่เด้งระหว่างโหวต
- **Given** ใช้คนเดียว **When** รีโหลดหน้า **Then** โหวตยังอยู่ (เก็บในเบราว์เซอร์)

ทดสอบโดย: TC-VOTE-01 ถึง TC-VOTE-05

#### US-04 โหวตรายร้าน · Should
**ในฐานะ** คนหิว **ฉันต้องการ** เลือก เห็นด้วย / ไม่เห็นด้วย กับร้านที่อยากหรือไม่อยากไปเป็นรายร้าน **เพื่อ** ปรับละเอียดกว่าระดับประเภทอาหาร

- ใช้สูตรเดียวกับประเภทอาหาร: ×(1 + 0.5 × คะแนนสุทธิ) ต่ำสุด ×0.1
- ใช้สวิตช์ 3 ช่องแบบเดียวกัน คนเดียวโหวตได้ร้านละ −1, 0, +1 ในห้องรวมคะแนนของทุกคน และแสดงผลรวมข้างสวิตช์ (เช่น "รวม +2")

ทดสอบโดย: TC-VOTE-06, TC-VOTE-07, TC-VOTE-08, TC-ROOM-09, TC-API-06

#### US-05 โหมดขี้เกียจเดิน · Must
**ในฐานะ** คนหิวที่ไม่อยากเดินไกล **ฉันต้องการ** เปิดสวิตช์ให้เหลือเฉพาะร้านใกล้ **เพื่อ** ไปถึงเร็ว

- **When** เปิด "ขี้เกียจเดิน" **Then** เหลือเฉพาะร้านที่เดินไม่เกิน **500 ม.** (ข้อมูลเริ่มต้นเหลือ 49 ร้าน)
- ในโหมดนี้ ร้านยิ่งใกล้ยิ่งมีโอกาสมาก: ×2.0 ที่หน้าออฟฟิศ ลดลงเป็นเส้นตรงจนเหลือ ×1.0 ที่ 500 ม.
- ถ้าไม่รู้ระยะเดินจริง ประมาณจากระยะเส้นตรง × 1.3
- ผลสุ่มทุกครั้งในโหมดนี้ต้องเดินไม่เกิน 500 ม. (ทดสอบซ้ำ 25 ครั้ง)
- **When** รีโหลดหน้า **Then** สวิตช์ยังเปิดอยู่

ทดสอบโดย: TC-FLT-01, TC-FLT-05, TC-FLT-06, TC-DRAW-02

#### US-06 กรองราคา · Must
**ในฐานะ** คนหิวช่วงปลายเดือน **ฉันต้องการ** เลือกช่วงราคาที่รับได้ **เพื่อ** ไม่ได้ร้านแพงเกินงบ

- ช่วงราคา: ฿ (ไม่เกิน 60) · ฿฿ (60–120) · ฿฿฿ (120–250) · ฿฿฿฿ (250 ขึ้นไป) · **ไม่ระบุ** (ร้านที่ยังไม่มีใครใส่ราคา)
- เลือกได้หลายช่วงพร้อมกัน กด "ทุกราคา" เพื่อล้างตัวกรอง
- **Given** ร้าน #1 ราคา ฿ และร้าน #2 ราคา ฿฿ **When** กด ฿ **Then** เหลือ 1 ร้าน 100% **When** กด ฿฿ เพิ่ม **Then** เหลือ 2 ร้าน ร้านละ 50%
- **Given** ยังไม่มีร้านไหนมีราคา **When** กด ฿ **Then** แสดง "ไม่มีร้านที่ตรงกับตัวกรองนี้" และปุ่มสุ่มร้านกดไม่ได้

ทดสอบโดย: TC-FLT-02, TC-FLT-03, TC-FLT-04

#### US-07 บันทึกว่าไปกินแล้ว · Must
**ในฐานะ** คนหิว **ฉันต้องการ** ยืนยันว่าไปกินร้านที่สุ่มได้จริง **เพื่อ** ไม่เจอร้านเดิมซ้ำในวันถัด ๆ ไป

- **When** กด "ไปกินร้านนี้" บนการ์ดผล **Then** ปุ่มเปลี่ยนเป็น "บันทึกว่ากินร้านนี้แล้ว" และแถวของร้านแสดง "ไปกินมาวันนี้ ×0.2" **ทันที** โดยไม่ต้องรีโหลด
- ตัวคูณเริ่มที่ ×0.2 ในวันที่กิน แล้วเพิ่มขึ้นเป็นเส้นตรงจนกลับเป็น ×1.0 เมื่อครบ 7 วัน
- **When** กดปุ่มอีกครั้ง **Then** ยกเลิกได้ โอกาสกลับเป็นปกติ
- **When** รีโหลดหน้า **Then** ยังแสดง "ไปกินมาวันนี้" (บันทึกที่ server)

ทดสอบโดย: TC-DRAW-04, TC-DRAW-05, TC-DRAW-06 (เคยพบ BUG-01 ตัวคูณไม่ลดจนกว่าจะรีโหลด แก้แล้ว)

#### US-08 ให้คะแนนร้านด้วยแมว · Should
**ในฐานะ** คนที่เพิ่งกินกลับมา **ฉันต้องการ** ให้คะแนนร้าน **เพื่อ** ให้ร้านอร่อยถูกสุ่มบ่อยขึ้น

- 4 ระดับ: อร่อยมาก (4) · โอเค (3) · เฉยๆ (2) · ไม่ไหว (1) แสดงเป็นรูปแมว
- เบราว์เซอร์หนึ่งเครื่องให้ได้ร้านละ 1 คะแนน เปลี่ยนหรือถอนคืนได้
- ตัวคูณจากคะแนนเฉลี่ย: เฉลี่ย 1 = ×0.6 ถึง เฉลี่ย 4 = ×1.4 · ยังไม่มีใครให้ = ×1.0
- ให้คะแนนได้จากการ์ดผลการสุ่ม และจากแผงร้านบนแผนที่ คนอื่นเห็นค่าเฉลี่ยใหม่ทันที

ทดสอบโดย: TC-RATE-01 ถึง TC-RATE-07

#### US-22 ดูร้านบนแผนที่ · Should
**ในฐานะ** คนหิว **ฉันต้องการ** สลับกระดานเป็นแผนที่ **เพื่อ** เห็นว่าร้านอยู่ตรงไหนเทียบกับออฟฟิศ

- **When** สลับเป็นมุมมองแผนที่ **Then** เห็นหมุดทุกร้านที่ผ่านตัวกรอง (เปิดขี้เกียจเดินแล้วเหลือหมุดตาม)
- หมุดที่มีโอกาสสูงมีขนาดใหญ่กว่า
- ชี้หมุดเห็นชื่อร้าน · กดหมุดแล้วแผงด้านขวาแสดงร้าน โอกาส ปุ่มโหวต และคะแนน · กดหมุดอื่นแล้วแผงเปลี่ยนตาม
- ร้านที่อยู่จุดเดียวกัน (ตึกเดียวกัน) มีรายการ "ร้านในจุดเดียวกัน" ให้เลือก
- สุ่มร้านบนแผนที่ได้ หมุดของร้านที่ได้เด่นขึ้น และสลับกลับไปมุมมองรายการได้
- ถ้าโหลดแผนที่พื้นหลังไม่ได้ หมุดยังต้องขึ้น

ทดสอบโดย: TC-MAP-01 ถึง TC-MAP-07 (เคยพบ BUG-03, BUG-04, BUG-05 แก้แล้ว)

#### US-23 ค้นหาร้าน · Should
**ในฐานะ** คนหิว **ฉันต้องการ** พิมพ์หาร้านที่อยากรู้โอกาส **เพื่อ** ไม่ต้องเลื่อนหาใน 237 ร้าน

- ช่องค้นหาเหนือกระดาน ค้นได้จากชื่อร้าน ชื่อเล่น ประเภทอาหาร หรือเบอร์ร้าน (`#12`)
- **When** พิมพ์ "ก๋วยเตี๋ยว" **Then** แสดงเฉพาะร้านที่ตรง และบอก "พบ N ร้าน"
- การค้นหา **ไม่เปลี่ยน** โอกาส จำนวนร้านที่สุ่มได้ หรือผลสุ่ม (แค่ซ่อนแถว)
- ถ้าร้านที่ตรงคำค้นถูกตัวกรองซ่อนไว้ บอกว่า "อีก N ร้านตรงคำค้นแต่ถูกตัวกรองซ่อนไว้"
- ล้างคำค้นด้วยปุ่ม X หรือ Esc แล้วกลับมาแสดง 15 อันดับแรก
- บนแผนที่ เหลือเฉพาะหมุดที่ตรง และแผงขวาแสดง "ผลการค้นหา N ร้าน"

ทดสอบโดย: TC-SEARCH-01 ถึง TC-SEARCH-05

### Epic B — ห้องกินด้วยกัน

#### US-09 เปิดห้อง · Must
**ในฐานะ** คนเปิดห้อง **ฉันต้องการ** สร้างห้องแล้วได้ลิงก์ไปแชร์ **เพื่อ** ชวนเพื่อนมาโหวตด้วยกัน

- **When** กด "สร้างห้อง" **Then** ได้ URL `/room/XXXX` รหัส 4 ตัว ที่ไม่มี 0, O, 1, I (อ่านออกเสียงง่าย)
- ตัวกรองที่ตั้งไว้ตอนเปิดห้อง (ขี้เกียจเดิน, ราคา) ติดไปกับห้อง

ทดสอบโดย: TC-ROOM-01

#### US-10 เข้าห้องด้วยชื่อเล่น · Must
**ในฐานะ** สมาชิกห้อง **ฉันต้องการ** เข้าห้องโดยใส่แค่ชื่อเล่น **เพื่อ** ไม่ต้องสมัครสมาชิก

- **Given** ยังไม่ใส่ชื่อเล่น **Then** ปุ่ม "เข้าห้อง" กดไม่ได้
- **When** ใส่ "ต้น" แล้วเข้าห้อง **Then** เห็น "ห้อง XXXX" และ "1 คนในห้อง · คุณคือ ต้น"
- ชื่อเล่นยาวได้ไม่เกิน 24 ตัวอักษร ใช้ชื่อเดิมซ้ำในห้องเดียวกัน = คนเดิม (ได้ member id เดิม)
- **When** คนที่สองเปิดลิงก์และเข้าห้อง **Then** จอของคนแรกเปลี่ยนเป็น "2 คนในห้อง" ภายใน 3 วินาที โดยไม่ต้องรีโหลด

ทดสอบโดย: TC-ROOM-01, TC-ROOM-02, TC-ROOM-07

#### US-11 โหวตร่วมกันแบบ realtime · Must
**ในฐานะ** สมาชิกห้อง **ฉันต้องการ** เห็นโหวตของเพื่อนทันที **เพื่อ** รู้ว่าทีมอยากกินอะไร

- โหวตของทุกคนรวมกันเป็นคะแนนสุทธิของแนว เช่น ต้น +1 มิว +1 → ส้มตำ +2 ×2.0
- การเปลี่ยนแปลงไปถึงทุกจอภายใน 3 วินาที
- คนที่ไม่ได้อยู่ในห้องโหวตไม่ได้ (404) · ประเภทอาหารที่ไม่มีอยู่หรือค่านอกจาก −1, 0, +1 ได้ 400

ทดสอบโดย: TC-ROOM-03, TC-API-01, TC-API-02, TC-API-05

#### US-12 ตัวกรองของห้องใช้ร่วมกัน · Must
**ในฐานะ** สมาชิกห้อง **ฉันต้องการ** ให้ตัวกรองเป็นของทั้งห้อง **เพื่อ** ทุกคนเห็นรายชื่อร้านชุดเดียวกัน

- **When** มิวเปิด "ขี้เกียจเดิน" **Then** จอของต้นเหลือ 49 ร้านและสวิตช์เปิดตาม
- **When** มิวกดราคา "ไม่ระบุ" **Then** จอของต้นขึ้น "กรองราคา" ภายใน 3 วินาที

ทดสอบโดย: TC-ROOM-04

#### US-13 สุ่มร้านในห้อง ทุกคนเห็นผลเดียวกัน · Must
**ในฐานะ** สมาชิกห้อง **ฉันต้องการ** ให้ใครก็ได้กดสุ่มร้าน แล้วทุกคนเห็นร้านเดียวกัน **เพื่อ** ไม่มีใครแอบสุ่มใหม่

- สุ่มที่ server ด้วยโหวตและตัวกรองของห้อง (ไม่ใช้ค่าที่ส่งมาจากเบราว์เซอร์)
- **When** ต้นกด "สุ่มร้าน" **Then** จอของมิวแสดงการ์ดผลเป็นร้านเดียวกัน
- การแก้ข้อมูลร้าน (เช่น ตั้งชื่อเล่น) ก็ไปถึงทุกจอภายใน 3 วินาที

ทดสอบโดย: TC-ROOM-05, TC-ROOM-06

#### US-14 ห้องที่ไม่มีอยู่หรือหมดอายุ · Could
**ในฐานะ** สมาชิกห้อง **ฉันต้องการ** รู้ทันทีถ้าลิงก์ห้องใช้ไม่ได้ **เพื่อ** ไม่ต้องรอเปล่า

- **When** เปิด `/room/ZZZZ` ที่ไม่มีอยู่ **Then** หน้า 404 และ API `GET /api/rooms/ZZZZ` ตอบ 404
- ห้องที่ไม่มีความเคลื่อนไหว 3 วัน ถูกลบอัตโนมัติ

ทดสอบโดย: TC-ROOM-08

### Epic C — ข้อมูลร้าน

#### US-15 แก้ข้อมูลร้าน · Must
**ในฐานะ** คนดูแลข้อมูลร้าน **ฉันต้องการ** แก้ข้อมูลร้านจากกระดาน **เพื่อ** ให้ตรงกับที่ทีมรู้จัก

- กดที่แถวร้านเพื่อเปิดหน้าแก้ไข
- **ชื่อเล่น** (ไม่เกิน 40 ตัวอักษร): แสดงแทนชื่อจริง มีชื่อจริงตัวเล็กอยู่ใต้ ลบจนว่างแล้วกลับเป็นชื่อจริง
- **ประเภทอาหาร**: ต้องเลือกอย่างน้อย 1 แนว ถ้าไม่เลือกเลย ปุ่มบันทึกกดไม่ได้ ตัวนับร้านของแนวอัปเดตตาม
- **ตัวคูณโอกาส**: 0.5–5 ขั้นละ 0.5 (ค่าเริ่ม ×1) เช่น ×2 ทำให้โอกาสเป็นสองเท่า → 2 ÷ 238
- **ราคา**: ฿ ถึง ฿฿฿฿ หรือไม่ระบุ
- บันทึกลงไฟล์ข้อมูล รีโหลดแล้วยังอยู่ · ค่าที่ไม่ถูกต้องได้ 400 · ร้านที่ไม่มีได้ 404

ทดสอบโดย: TC-EDIT-01, TC-EDIT-02, TC-EDIT-04 ถึง TC-EDIT-07, TC-API-03

#### US-16 ปิด / เปิดร้าน · Must
**ในฐานะ** คนดูแลข้อมูลร้าน **ฉันต้องการ** ปิดร้านที่เลิกกิจการหรือไม่มีใครไป **เพื่อ** ไม่ให้ถูกสุ่มอีก

- **When** กด "ไม่สุ่มร้านนี้" **Then** ร้านหายจากกระดาน จำนวนร้านลดลง 1 และไม่ถูกสุ่มอีก
- รายการ "ร้านที่ไม่สุ่ม" แสดงจำนวนและรายชื่อ กด "กลับมาสุ่ม" เพื่อคืนร้าน

ทดสอบโดย: TC-EDIT-03, TC-DRAW-03

#### US-17 เพิ่มร้านเอง · Should
**ในฐานะ** คนดูแลข้อมูลร้าน **ฉันต้องการ** เพิ่มร้านที่ไม่มีในแผนที่ **เพื่อ** ให้ร้านเปิดใหม่ถูกสุ่มได้ด้วย

- หน้า `/restaurants/new`: ใส่ชื่อร้าน (ไม่เกิน 80 ตัวอักษร) และประเภทอาหารอย่างน้อย 1 แนว ส่วนชื่อเล่น ราคา และเวลาเปิด ไม่บังคับ
- ระบุตำแหน่งได้โดยจิ้มบนแผนที่ หรือวางพิกัด / ลิงก์ Google Maps
- ร้านต้องอยู่ไม่เกิน **2 กม.** จากออฟฟิศ ไม่อย่างนั้นแจ้ง "ร้านอยู่ไกลเกิน 2 กม. จากออฟฟิศ"
- ระบบคำนวณระยะเดินจริงให้ ถ้าบริการคำนวณเส้นทางไม่ตอบใน 4 วินาที ใช้ระยะเส้นตรง × 1.3
- ร้านที่เพิ่มเองลบได้ ส่วนร้านจาก OpenStreetMap ลบไม่ได้ ให้ใช้ปิดร้านแทน (409)
- ร้านใหม่ขึ้นบนกระดานของทุกคนทันที (เคยพบ BUG-02 ต้องรีโหลดก่อน แก้แล้ว)

ทดสอบโดย: TC-ADD-01 ถึง TC-ADD-09

#### US-18 จัดการประเภทอาหาร · Should
**ในฐานะ** คนดูแลข้อมูลร้าน **ฉันต้องการ** เพิ่ม เปลี่ยนชื่อ หรือลบประเภทอาหาร **เพื่อ** ให้หมวดตรงกับร้านแถวออฟฟิศ

- หน้า `/categories` แสดงทุกแนวพร้อมจำนวนร้าน (ไม่นับร้านที่ปิด)
- ชื่อแนวห้ามว่าง ยาวไม่เกิน 30 ตัวอักษร และห้ามซ้ำ (ซ้ำได้ 409 "มีประเภทอาหารนี้อยู่แล้ว")
- ลบแนวแล้ว แนวนั้นหายจากทุกร้านและจากโหวตในทุกห้อง
- แนวที่เพิ่มใหม่ใช้โหวตได้ทันที

ทดสอบโดย: TC-CAT-01 ถึง TC-CAT-05

### Epic D — ประวัติ

#### US-19 ดูประวัติและแชมป์ · Should
**ในฐานะ** คนหิว **ฉันต้องการ** ดูว่าสุ่มได้ร้านไหนมาบ้าง **เพื่อ** รู้ว่าทีมไปไหนบ่อย

- เมนู "ประวัติ" ไปหน้า `/history` หัวข้อ "สุ่มได้บ่อยใน 7 วัน"
- รายการล่าสุดเรียงใหม่สุดก่อน ทุกแถวมีป้ายสถานะ: **ไปกิน** / **ไม่ได้ไปกิน** / **รอยืนยัน** และบอกว่าสุ่มในโหมดขี้เกียจเดินหรือไม่
- **Given** ยังไม่มีการสุ่ม **Then** ทั้งสองส่วนแสดง "ยังไม่เคยสุ่ม"
- เก็บผลการสุ่มล่าสุดไม่เกิน 1,000 ครั้ง

### Epic E — มือถือ

#### US-20 ใช้บนมือถือได้สะดวก · Must
**ในฐานะ** คนหิวที่ถือมือถือเดินออกจากออฟฟิศ **ฉันต้องการ** กดสุ่มร้านได้ทันทีที่เปิดเว็บ **เพื่อ** ไม่ต้องเลื่อนหา

- จอ 390×844: ปุ่มสุ่มร้านอยู่เหนือโอกาสของแต่ละร้าน และเห็นได้โดยไม่ต้องเลื่อน
- หน้าไม่กว้างเกินจอ (ไม่มี scroll แนวนอน)
- **When** กดสุ่มร้าน **Then** การ์ดผลเลื่อนขึ้นมาอยู่ในจอ (อย่างน้อย 30% ของการ์ด)

ทดสอบโดย: TC-MOB-01, TC-MOB-02

### Epic F — รองรับการทดสอบ

#### US-21 ล้างข้อมูลก่อนทดสอบ · Must
**ในฐานะ** ผู้ทดสอบ **ฉันต้องการ** คืนข้อมูลเป็นค่าเริ่มต้นได้ด้วยคำสั่งเดียว **เพื่อ** ให้ทุกเทสต์เริ่มจากสภาพเดียวกัน

- `POST /api/test/reset` คืนร้าน ประเภทอาหาร คะแนน ห้อง และผลการสุ่มเป็นค่าเริ่มต้น (237 ร้าน, 16 แนว)
- ใช้ได้เฉพาะเมื่อเปิดเซิร์ฟเวอร์ด้วย `LUNCH_TEST=1` ไม่อย่างนั้นตอบ 404
- ในโหมดทดสอบ ไม่เรียกบริการคำนวณเส้นทางภายนอก เพื่อให้ผลไม่ขึ้นกับอินเทอร์เน็ต
- ข้อมูลทดสอบแยกโฟลเดอร์ (`e2e/.data`) ไม่ปนกับข้อมูลจริง

ทดสอบโดย: ใช้ใน setup ของทุก test

## 5. สูตรโอกาส (สรุปจากทุก story)

```
น้ำหนักร้าน = ตัวคูณโอกาส            (US-15  0.5–5)
            × ตัวคูณแนวที่ดีที่สุด        (US-03  1 + 0.5 × โหวต, ต่ำสุด 0.1)
            × ตัวคูณโหวตรายร้าน         (US-04  สูตรเดียวกัน)
            × ตัวคูณกินไปแล้ว           (US-07  0.2 → 1.0 ภายใน 7 วัน)
            × ตัวคูณระยะใกล้            (US-05  2.0 → 1.0 เฉพาะโหมดขี้เกียจเดิน)
            × ตัวคูณคะแนนแมว           (US-08  0.6 → 1.4)

โอกาส % = น้ำหนักร้าน ÷ ผลรวมน้ำหนักของทุกร้านที่ผ่านตัวกรอง (US-05, US-06, US-16)
```
