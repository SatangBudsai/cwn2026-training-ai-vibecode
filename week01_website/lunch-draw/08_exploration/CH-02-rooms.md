- ไม่มีโหวตรั่วข้ามห้อง ทั้งทาง API (404) และ SSE (event ส่งเฉพาะห้อง)

- SSE ส่ง state ล่าสุดทุกครั้งที่ต่อใหม่ ห้องที่ไม่มีอยู่ได้ `room: null` และ client ข้ามไป

- **ทดสอบ UI หลายเบราว์เซอร์จริง** (Playwright) ไม่ได้ทำเพราะ `.next` ไม่ตรงกับเซิร์ฟเวอร์ :3302 ควรรีสตาร์ต :3302 แล้วรัน `ui.cjs` (S1 สุ่มชนกันพร้อมเน็ตช้า, S2 offline/online ของ EventSource, S3 โหวตหลังห้องหาย, S4 URL ตัวเล็กและชื่อซ้ำ 2 เครื่อง) เพื่อยืนยัน F02-01, F02-02, F02-08 บนจอ
- EventSource ของเบราว์เซอร์ต่อใหม่เองหลังเซิร์ฟเวอร์รีสตาร์ต (ไม่ได้รีสตาร์ตเพราะไม่ใช่สิทธิ์ของเรา)
- listener รั่วหลังผู้ใช้ปิดแท็บจำนวนมาก (`subscribe` / `cleanup`) วัดจากภายนอกไม่ได้
- ห้องหมดอายุ 3 วัน (ต้องแก้เวลา) และผลต่อคนที่เปิดหน้าค้างไว้
- ลบแนวอาหารระหว่างที่ห้องมีโหวต (`deleteCategory` ส่ง event ห้อง) ซึ่งทับกับ CH-03
- กด "กินแล้ว" พร้อมกันหลายคน และ `setEaten` สลับกัน
