## สิ่งที่ยังไม่ได้สำรวจ

- **UI จริง** ของช่องวางลิงก์, แผงแก้ไขร้านที่ `categories: []`, และการแสดงอีโมจิที่ถูกตัดครึ่ง: ทำไม่ได้เพราะ `.next` ถูก build ใหม่ระหว่างที่เซิร์ฟเวอร์รัน (chunk 404) ควรตรวจซ้ำหลังรีสตาร์ต :3303
- ไฟล์ JSON เสีย/ถูกแก้จากภายนอก: จากโค้ด ถ้า `restaurants.json` parse ไม่ได้ตอนเริ่ม จะได้ `[]` และการเขียนครั้งถัดไปจะ**ทับไฟล์ด้วยรายการว่าง** (ตรวจจากโค้ดเท่านั้น ไม่ได้ทดลองเพราะห้ามแก้ไฟล์ข้อมูล) ควรมีคนทดสอบในโฟลเดอร์ทิ้งได้
- `walkingDistance` จริง (ข้ามในโหมด `LUNCH_TEST`) และการเพิ่มร้านพร้อมกันขณะรอบริการเส้นทาง 4 วินาที
- ผลของ F03-01 ต่อหน้าแชมป์ 7 วัน และ SSE event ที่ส่งไปให้ห้องอื่นเมื่อลบแนว (CH-02)
- ขนาด payload: label 5 MB ถูกปฏิเสธ 400 แต่ไม่ได้ลองชื่อร้าน/ร้านจำนวนมาก (สแปมร้านหลักพัน)
