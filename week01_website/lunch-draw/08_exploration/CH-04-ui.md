### สิ่งที่ตรวจแล้วทำงานถูกต้อง
- **ลำดับ Tab สมเหตุสมผล:** โลโก้ → เมนู 3 ลิงก์ → สวิตช์ขี้เกียจเดิน → ราคา 5 ปุ่ม → **สุ่มร้าน (Tab ครั้งที่ 11)** → สร้างห้อง → จัดการประเภทอาหาร → โหวตแนว (Tab ครั้งที่ 14–45) → รายการ/แผนที่ → แถวกระดาน ทุก element มีกรอบ focus `outline 2px` สวิตช์เป็น `<input role=switch>` ที่ซ่อนไว้ (1×1 px) และกรอบ focus แสดงบนตัวสวิตช์ผ่าน `peer-focus-visible`
- Enter สุ่มได้ (`winner via Enter: 199`) Space เปิดขี้เกียจเดินได้ (237→49) Enter โหวตแนวได้ ("โหวตแล้ว 1 แนว") และ Enter ที่หมุดเลือกร้านในแผงได้
- **ปุ่มไอคอนทุกปุ่มมีชื่อ:** − / + มี `aria-label` เช่น "ไม่อยากกินข้าวแกง" และ "อยากไปร้าน ครัวอร๊อย-อร่อย" ปุ่มคะแนนแมวมี "ให้คะแนน อร่อยมาก" ปุ่มปิดแผงแผนที่มี "ปิด" ปุ่มน้ำหนัก ± มี `aria-label` หมุดมีชื่อร้านพร้อม % และสถานะกดใช้ `aria-pressed` / `aria-checked` / `aria-expanded` ถูกต้อง
- มือถือ: ปุ่ม "สุ่มร้าน" อยู่ที่ y=393 (เห็นโดยไม่ต้องเลื่อน) หลังแตะสุ่ม หน้าเลื่อนไปที่การ์ดผล (`winner top y=10`) ตาม US-20 · `/history`, `/restaurants/new`, `/categories` และมุมมองรายการไม่มี scroll แนวนอน ข้อความไทยยาวถูกตัดด้วย `truncate` ไม่ล้นจอ
- ตัวกรองไม่เหลือร้าน: ปุ่มถูก disable กระดานแสดง "ไม่มีร้านที่ตรงกับตัวกรองนี้" แผนที่ 0 หมุดโดยไม่ error และหมุดกลับมาเมื่อล้างตัวกรอง
- บล็อกเน็ตภายนอกแล้วหมุดยังขึ้นครบ (237 / 49) สุ่มบนแผนที่แล้วหมุดของผู้ชนะได้ `data-tone=lit`
- console: หลัง build ใหม่**ไม่มี error จากแอป** มีแค่ `AJAXError … cartocdn style.json` / `net::ERR_FAILED` (เกิดจากการบล็อกเน็ตตามที่ตั้งใจ) และ warning ของ WebGL driver

## สิ่งที่ยังไม่ได้สำรวจ
- โปรแกรมอ่านจอจริง (NVDA / VoiceOver) ทดสอบแค่ชื่อที่ได้จาก DOM
- ห้อง (`/room/CODE`) บนมือถือ และหน้า JoinRoom ด้วยคีย์บอร์ด
- ฟอร์ม `/restaurants/new` ด้วยคีย์บอร์ด (ปักหมุดด้วยคีย์บอร์ดทำได้ไหม) และข้อความ error ของฟอร์ม
- ทำให้เกิดแถว `<0.1%` บนจอแล้วดูผลรวม (ต้องใช้ตัวคูณหลายตัวพร้อมกัน ซึ่งอยู่ในขอบเขต CH-01)
- dark/light, ซูม 200%, `prefers-reduced-motion` (แอนิเมชันสุ่มไม่สนใจค่านี้ แต่ยังไม่ได้ตรวจ)
- แผนที่บนมือถือ: pinch-zoom และการแตะหมุดที่ซ้อนกัน ("ร้านในจุดเดียวกัน")
