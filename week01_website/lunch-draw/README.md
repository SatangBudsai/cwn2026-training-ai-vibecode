# ข้าวไหนดี · สีลม

จับสลากร้านข้าวกลางวันรอบอาคารจันวาณิชย์ (สีลม) ในระยะเดิน 1 กม. ตามแนวอาหารที่ทีมโหวต

- **โหวตแนวอาหาร** กด + แนวที่อยากกิน กด − แนวที่ไม่เอา (ก๋วยเตี๋ยว, ข้าวแกง, ส้มตำ, ญี่ปุ่น ...)
- **ขี้เกียจเดิน** เหลือเฉพาะร้านที่ระยะเดินจริงไม่เกิน 500 ม. (49 ร้าน)
- **ห้อง (member)** เปิดห้อง แชร์ลิงก์ ทุกคนโหวตพร้อมกัน ใครกดจับสลากก็ได้ ทุกคนเห็นผลเดียวกัน
- **กินไปแล้ว 7 วัน** กด "ไปกินร้านนี้" บนผลจับสลาก ร้านนั้นจะมีโอกาสน้อยลง แล้วค่อยๆ กลับมาปกติใน 7 วัน
- **แก้ข้อมูลร้าน** กดที่แถวในกระดานโอกาส เพื่อแก้แนวอาหารของร้าน หรือปรับน้ำหนักพื้นฐาน (0 = ไม่สุ่มร้านนี้)

## สูตรน้ำหนัก

```
น้ำหนักร้าน = น้ำหนักพื้นฐาน (0–5)
            × ตัวคูณแนวอาหารที่ดีที่สุดของร้าน   max(0.1, 1 + 0.5 × ผลโหวตสุทธิของแนวนั้น)
            × ตัวคูณกินไปแล้ว                    0.2 วันที่กิน → 1.0 เมื่อครบ 7 วัน (เพิ่มแบบเส้นตรง)
โอกาส       = น้ำหนักร้าน / ผลรวมน้ำหนักของทุกร้านที่ผ่านตัวกรอง
```

โค้ดอยู่ที่ `src/lib/odds.ts` และเทสต์อยู่ที่ `src/lib/odds.test.ts`

## เริ่มใช้งาน

```bash
npm install          # รัน prisma generate และคัดลอก worker ของ MapLibre ให้อัตโนมัติ
npm run db:setup     # สร้าง SQLite dev.db และ seed 237 ร้านจาก data/restaurants.json
npm run dev
```

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run data:fetch` | ดึงร้านใหม่จาก OpenStreetMap คำนวณระยะเดินจริง แล้ว seed ลง DB (ค่าที่แก้ในแอปจะไม่หาย) |
| `npm run db:studio` | เปิด Prisma Studio ดูหรือแก้ข้อมูล |
| `npm test` | unit test ของสูตรน้ำหนัก |

พิกัดจุดศูนย์กลางอยู่ที่ `src/lib/geo.ts` (`OFFICE`) **เป็นพิกัดประมาณ** ถ้าแก้แล้วให้รัน `npm run data:fetch` ใหม่

## Stack

Next.js 16 (App Router, Route Handlers เป็นหลังบ้าน) · Prisma 7 + SQLite (better-sqlite3 adapter) · Tailwind v4 · MapLibre + CARTO dark tiles · lucide icons
ข้อมูลร้านจาก OpenStreetMap และระยะเดินจาก routing.openstreetmap.de ทั้งหมดฟรี ไม่ต้องใช้ API key

ตอน deploy ขึ้น Vercel ต้องเปลี่ยนจาก SQLite เป็น Postgres ที่ host ไว้ (เช่น Prisma Postgres หรือ Neon) เพราะ Vercel ไม่มี disk ถาวร
ทำได้โดยเปลี่ยน `provider` ใน `prisma/schema.prisma` และเปลี่ยน adapter ใน `src/lib/db.ts`
