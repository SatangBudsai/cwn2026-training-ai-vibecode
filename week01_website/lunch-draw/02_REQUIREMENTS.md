# 📐 Requirements — ข้าวไหนดี (lunch-draw)

ต่อจาก `01_USER-STORIES.md` หลังทีม ("ร้าน" = ทีมที่ใช้งาน) ตอบกลับ story ทุกข้อ แล้วแตกเป็น 3 กลุ่ม

| กลุ่ม | ย่อ | ตอบคำถาม |
|---|---|---|
| Functional Requirement | **FR** | ระบบต้อง **ทำอะไร** ได้ |
| Business Rule | **BR** | ตัวเลขและกติกาที่ **ต้องถูกเป๊ะ** |
| Non-Functional Requirement | **NFR** | ต้องทำได้ **ดีแค่ไหน** (เร็ว ปลอดภัย ใช้ง่าย) |

ทุกข้อในเอกสารนี้ตรงกับโค้ดปัจจุบัน และอ้างไฟล์ที่ใช้ตรวจได้

## 3. Business Rules (BR)

ส่วนนี้คือ "เงิน" ของระบบ ถ้าผิด ผลสุ่มไม่ยุติธรรม ทุกข้อจึงต้องมี test ที่คิดตัวเลขซ้ำ (ดู `04_TEST-DATA.md`)

### 3.1 สูตรโอกาส (`src/lib/odds.ts`)

| ID | กติกา | ค่า |
|---|---|---|
| **BR-01** | โอกาสของร้าน = น้ำหนักร้าน ÷ ผลรวมน้ำหนักของทุกร้านที่ผ่านตัวกรอง | ผลรวมทุกร้าน = 100% |
| **BR-02** | น้ำหนักร้าน = ตัวคูณโอกาส × ตัวคูณแนว × ตัวคูณโหวตร้าน × ตัวคูณกินแล้ว × ตัวคูณระยะ × ตัวคูณคะแนน | 6 ตัวคูณ |
| **BR-03** | ตัวคูณโหวต (ทั้งแนวและร้าน) = max(0.1, 1 + 0.5 × คะแนนสุทธิ) | +1 → 1.5 · −1 → 0.5 · −2 → 0.1 (ชนพื้น) |
| **BR-04** | ร้านหลายแนวใช้ตัวคูณของแนวที่ **สูงที่สุด** · ร้านไม่มีแนว = ×1 | |
| **BR-05** | ตัวคูณโอกาส 0.5–5 ปัดเป็นขั้นละ 0.5 · ค่าเริ่มต้น 1 | 0.74 → 0.5 · 0.75 → 1 |
| **BR-06** | ตัวคูณกินแล้ว = 0.2 + 0.8 × (วันที่ผ่านไป ÷ 7) · ครบ 7 วัน = 1 · เวลาในอนาคตนับเป็นวันนี้ | วันที่ 0 → 0.2 · วันที่ 3.5 → 0.6 |
| **BR-07** | ขี้เกียจเดิน: ตัดร้านที่ระยะเดิน > 500 ม. | ≤ 500 อยู่ · 501 หลุด |
| **BR-08** | ตัวคูณระยะ (เฉพาะขี้เกียจเดิน) = 1 + (1 − ระยะเดิน ÷ 500) | 0 ม. → 2.0 · 250 ม. → 1.5 · 500 ม. → 1.0 |
| **BR-09** | ไม่รู้ระยะเดินจริง → ระยะเดิน = round(ระยะเส้นตรง × 1.3) | |
| **BR-10** | ช่วงราคา: 1 = ฿ (≤ 60) · 2 = ฿฿ (60–120) · 3 = ฿฿฿ (120–250) · 4 = ฿฿฿฿ (250+) · 0 = ไม่ระบุ · ไม่เลือก = ไม่กรอง | |
| **BR-11** | ตัวคูณคะแนน = 0.6 + (เฉลี่ย − 1) ÷ 3 × 0.8 · ยังไม่มีคะแนน = 1 · คะแนนเฉลี่ยปัด 2 ตำแหน่ง | เฉลี่ย 1 → 0.6 · 2.5 → 1.0 · 4 → 1.4 |
| **BR-12** | ร้านที่ปิด ไม่อยู่ในการคำนวณและไม่ถูกสุ่ม | |
| **BR-13** | สุ่มด้วย `crypto.getRandomValues` ตามน้ำหนัก (roulette wheel) · ไม่มีร้านเหลือ → 409 | |
| **BR-14** | การแสดง %: 0 → "0%" · < 0.1% → "<0.1%" · อื่น ๆ ทศนิยม 1 ตำแหน่ง · เรียงตาม % มาก → น้อย ถ้าเท่ากันเรียงเลขร้าน | 1/237 → "0.4%" |

### 3.2 กติกาข้อมูล

| ID | กติกา |
|---|---|

| **BR-17** | เพิ่มร้านได้เฉพาะระยะเส้นตรงไม่เกิน 2,000 ม. จากออฟฟิศ (13.7247, 100.5245) |
| **BR-18** | ร้านที่เพิ่มเองได้เลขถัดจากเลขสูงสุด · เลขร้านไม่ถูกใช้ซ้ำแม้ดึงข้อมูล OSM ใหม่ |
| **BR-19** | ความยาว: ชื่อร้าน 80 · ชื่อเล่นร้าน 40 · ชื่อประเภทอาหาร 30 · ชื่อเล่นในห้อง 24 · ชื่อผู้ให้คะแนน 24 · เวลาเปิด 80 (เกินตัดทิ้ง ยกเว้นชื่อแนวที่ตอบ 400) |
| **BR-20** | ชื่อประเภทอาหารห้ามว่างและห้ามซ้ำ (409) · ลบแนวแล้วเอาออกจากทุกร้านและทุกโหวตในห้อง |
| **BR-21** | 1 เบราว์เซอร์ (`rater` 8–64 ตัว `[A-Za-z0-9_-]`) ให้ได้ร้านละ 1 คะแนน · score 1–4 · 0 = ถอนคะแนน |
| **BR-22** | รหัสห้อง 4 ตัวจาก `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (ไม่มี 0 O 1 I) · ไม่สนตัวพิมพ์เล็ก/ใหญ่ |
| **BR-23** | คนเดียวโหวตได้แนวละ / ร้านละ −1, 0, +1 · ในห้อง คะแนนสุทธิ = ผลรวมของทุกสมาชิก · คนนอกห้องโหวตไม่ได้ (404) |
| **BR-24** | ห้องที่ไม่มีความเคลื่อนไหว 3 วันถูกลบ · เก็บผลการสุ่ม 1,000 ครั้งล่าสุด |
| **BR-25** | "กินไปแล้ว" นับจากผลการสุ่มที่ยืนยัน (`eatenAt`) ภายใน 7 วัน ใช้ครั้งล่าสุดของแต่ละร้าน |
| **BR-26** | ป้ายในประวัติ: ยืนยันแล้ว = **ไปกิน** · เป็นผลล่าสุดของห้องนั้น (หรือของการใช้คนเดียว) และสุ่มมาไม่เกิน 2 ชม. = **รอยืนยัน** · นอกนั้น = **ไม่ได้ไปกิน** · แสดง 30 รายการล่าสุด |
| **BR-27** | แชมป์ 7 วัน = 5 ร้านที่ **ถูกสุ่มได้** บ่อยที่สุดใน 7 วัน (นับทุกผล ไม่ว่าไปกินหรือไม่) |
| **BR-28** | เวลาเดิน (นาที) = max(1, round(ระยะเดิน ÷ 80)) · คิดความเร็วเดิน 80 ม./นาที |
