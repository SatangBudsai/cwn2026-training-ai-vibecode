## 6. แบ่งงานให้ writer

test เดิมแบ่งตามไฟล์ที่มีอยู่แล้ว ส่วน test ใหม่แต่ละ writer เขียนใน **ไฟล์ใหม่ของตัวเอง** เพื่อไม่ชนกันและไม่ชนกับไฟล์ที่เจ้าของกำลังแก้

> **แก้ตาม R-02 / R-03:** แบ่งงานตาม **ไฟล์** ไม่ใช่ตาม story (ไฟล์ `x-*.spec.ts` ละ 1 writer) · writer แต่ละคนรันด้วย `e2e/playwright.writer.config.ts` กับเซิร์ฟเวอร์และโฟลเดอร์ข้อมูลของตัวเอง (W1 `:3301`, W2 `:3302`, W3 `:3303` แต่ละพอร์ตมี `LUNCH_DATA_DIR` แยก และรันจาก build snapshot เดียวกันที่ไม่ถูก build ทับ) · รันชุดเต็มอย่างเป็นทางการครั้งเดียวด้วย `npm run e2e:all` หลังทุกคนเขียนเสร็จ

| Writer | ดูแล | ไฟล์เดิม (ดูแล) | ไฟล์ใหม่ (เขียน) | test ใหม่ |
|---|---|---|---|---|
| **W1 ห้องและ realtime** | US-09 ถึง US-14 | `room.spec.ts`, `picks.spec.ts` | `e2e/tests/x-room.spec.ts` | TC-ROOM-10 ถึง TC-ROOM-13 |
| **W2 สูตร สุ่ม และ API** | US-01 ถึง US-08, US-21 | `home.spec.ts`, `vote.spec.ts`, `filter.spec.ts`, `draw.spec.ts`, `rating.spec.ts`, `history-api.spec.ts` | `e2e/tests/x-draw-api.spec.ts` | TC-DRAW-07, TC-DRAW-08, TC-HOME-05, TC-API-07 ถึง TC-API-11 |
| **W3 ข้อมูลร้าน และหน้าจอ** | US-15 ถึง US-20, US-22, US-23 | `edit.spec.ts`, `add.spec.ts`, `categories.spec.ts`, `map.spec.ts`, `search.spec.ts` | `e2e/tests/x-data-ui.spec.ts` | TC-ADD-10 ถึง TC-ADD-12, TC-CAT-06, TC-MOB-03, TC-ACC-01, TC-MAP-08 |
| **ทดสอบด้วยมือ** | — | — | — | TC-API-12 (ต้องปิดเปิดเซิร์ฟเวอร์) |

กติกาสำหรับ writer
1. ใช้ helper ใน `e2e/fixtures.ts` (`openHome`, `draw`, `createRoom`, `newMember`, `setRestaurant`, `row`, `rowPercent`, `pct`) ห้ามแก้ไฟล์นี้ ถ้าต้องการ helper เพิ่มให้เขียนไว้ในไฟล์ของตัวเอง
2. ตั้งชื่อ test เป็น `TC-XXX-NN ชื่อ @P1|P2|P3` และส่งรายละเอียดให้ผู้รวม (`pre`, `steps`, `expected`) เพื่อเพิ่มใน `e2e/test-cases.json`
3. ตัวเลข % ต้องมาจากสูตร (`pct(...)`) หรือจาก `04_TEST-DATA.md` ไม่ hard-code ผลที่ได้จากจอ
4. assert พฤติกรรม **ที่ถูกต้อง** ตาม story / BR แม้แอปตอนนี้จะยังผิด
5. test ที่ใช้หลายเบราว์เซอร์ต้องปิด context ที่เปิดเองทุกครั้ง
