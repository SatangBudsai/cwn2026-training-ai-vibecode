# 🧪 Test Data — ข้าวไหนดี (lunch-draw)

ข้อมูลที่ใช้ทดสอบ และตัวเลขที่ "คิดซ้ำ" ไว้ล่วงหน้า เพื่อให้ผู้ทดสอบรู้ผลที่ถูกต้องก่อนเปิดเว็บ

> **คิดเงินซ้ำ (double calculation)** ระบบนี้ไม่มีเงิน แต่ "เงิน" ของมันคือ **% โอกาส** ถ้าผิด การสุ่มไม่ยุติธรรม
> เราจึงเขียนสูตรใหม่อีกชุดจาก `02_REQUIREMENTS.md` โดยไม่ดูโค้ดแอป (`04_test-data/recompute-odds.ts`) แล้วเทียบกับโค้ดจริง `src/lib/odds.ts` ทุกร้าน ทุกสถานการณ์

## 4. การสุ่ม: ตรวจว่าผลจริงตรงกับ %

การคิด % ให้ถูกยังไม่พอ ต้องตรวจว่าสุ่มจริงแล้วออกตาม % ด้วย

| วิธี | ตั้งค่า | คาดหวัง |
|---|---|---|
| สุ่มซ้ำผ่าน API | `POST /api/draw {lazy:true}` × 25 | ทุกร้านที่ได้เดิน ≤ 500 ม. (TC-DRAW-02) |
| เหลือร้านเดียว | ปิดทุกร้านในระยะ 500 ม. ยกเว้น 1 ร้าน แล้วสุ่ม 10 ครั้ง | ได้ร้านนั้นทุกครั้ง โอกาส 100% (TC-DRAW-03) |
| ความถี่ | กรอง ฿ + ฿฿ (2 ร้าน 50/50) สุ่ม 1,000 ครั้ง | แต่ละร้านได้ 450–550 ครั้ง (ช่วง ±3σ ≈ ±47) |
| น้ำหนักต่าง | 2 ร้าน น้ำหนัก ×1 กับ ×4 (20/80) สุ่ม 1,000 ครั้ง | ร้าน ×4 ได้ 760–840 ครั้ง |

ผลจริงของการสุ่มจำนวนมาก บันทึกโดยผู้สำรวจ CH-01 ใน `08_exploration/CH-01-odds.md`
