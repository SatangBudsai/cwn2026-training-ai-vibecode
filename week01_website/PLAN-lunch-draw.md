# แผนงาน: เว็บสุ่มร้านข้าวแถวจันวาณิชย์ ("ข้าวไหนดี")

## 1. เป้าหมาย

> **อัปเดต (6 พ.ย. 2026):** สร้างแล้วที่ `lunch-draw/` ด้วย Next.js + Prisma (SQLite)
> - **ตัดการสุ่มเมนูออก** เปลี่ยนเป็นติดแนวอาหารให้แต่ละร้าน แล้วให้ member โหวตว่าวันนี้อยากกินแนวไหน
> - **เพิ่มกติกา:** ร้านที่กดว่า "ไปกินร้านนี้" ภายใน 7 วัน น้ำหนักจะลดลง
> - ใช้ Prisma แทน Supabase
> - สูตรล่าสุดดูที่ `lunch-draw/README.md`

สุ่มร้านอาหารในระยะ 1 กม. รอบอาคารจันวาณิชย์ (สีลม ระหว่างซอย 11–13) โดยปรับ weight ได้ว่าแต่ละร้านควรถูกเลือกกี่ %

| ฟีเจอร์ | รายละเอียด |
| --- | --- |
| สุ่มร้าน | สุ่มแบบถ่วงน้ำหนัก (weighted random) จากร้านที่ผ่านตัวกรอง |
| สุ่มเมนู | สุ่มเมนูในร้านที่ได้ ตาม weight ของแต่ละเมนู |
| ระบบ weight | ปรับ weight ร้าน/เมนูเองได้ และแสดงเป็น % ที่แต่ละร้านจะถูกเลือก |
| Mode ขี้เกียจเดิน | กรองเหลือร้านที่ระยะเดินไม่เกิน 500 ม. |
| Mode member | สร้างห้อง แชร์ลิงก์ให้คนที่จะไปกินด้วยกันมาโหวต +/- เพื่อเพิ่มหรือลด weight |

## 2. ข้อมูลร้านอาหาร (สำรวจแล้ว)

- **จุดศูนย์กลาง (ประมาณ):** `13.7247, 100.5245` อาคารกองบุญมา ถ.สีลม ระหว่างซอย 11–13 (ใกล้ BTS เซนต์หลุยส์) **ต้องยืนยันพิกัดจริงอีกครั้ง**
- **แหล่งข้อมูล:** OpenStreetMap ผ่าน Overpass API (ฟรี ไม่ต้องใช้ key)
- **ผลที่ได้:** ร้านที่มีชื่อ 338 แห่งในรัศมี 1 กม. (restaurant 219, cafe 101, fast food 15, food court 3)
  - ไม่นับคาเฟ่ เหลือ **237 ร้าน** โดย **95 ร้าน** อยู่ในระยะ 500 ม.
  - มีเวลาเปิดปิดแค่ 39 ร้าน และ **ไม่มีข้อมูลเมนูเลย**
- **ตัวอย่างร้านที่ใกล้ที่สุด:** ครัวอร๊อย-อร่อย (152 ม.), วัดแขกก๋วยจั๊บ, ข้าวหมูกรอบ, ข้าวแกงเจ๊สม, สีลม ฮาลาลฟู้ด, โกนัน, จุ๊บ จุ๊บ เย็นตาโฟ, รสแกงใต้, เตี๋ยวสีลม, ส้มตำป้าน้อย, วาชิน ราเม็ง, บ้านเป็ดสุขใจ ...

### Pipeline ข้อมูล

1. `scripts/fetch-osm.ts` ดึงข้อมูลจาก Overpass แล้วคำนวณระยะ และเขียนเป็น `data/restaurants.json`
2. `scripts/walk-distance.ts` คำนวณ **ระยะเดินจริง** ครั้งเดียวผ่าน `routing.openstreetmap.de` (OSRM โปรไฟล์ foot ฟรี) เพราะระยะเส้นตรงไม่ตรงกับทางเดินจริง (ต้องอ้อมซอย)
3. **ข้อมูลเมนู:** ใส่ด้วยมือ (curate) เริ่มจากร้านใน 500 ม. ร้านที่ยังไม่มีเมนู ให้ใช้เมนูตั้งต้นตามประเภทร้าน (ก๋วยเตี๋ยว, ข้าวแกง, ส้มตำ ...) และเปิดให้คนในทีมเพิ่มเมนูผ่านหน้าเว็บได้
4. ทุกร้านมีปุ่ม "เปิดใน Google Maps" เป็น deep link (ฟรี ไม่ต้องใช้ API):
   `https://www.google.com/maps/search/?api=1&query=<lat>,<lon>`

## 3. ใช้ Google Maps ฟรีได้ไหม

**ได้บางส่วน แต่ไม่จำเป็นต้องใช้** ตั้งแต่ มี.ค. 2025 Google เลิกเครดิต $200/เดือน และเปลี่ยนเป็นโควตาฟรีแยกตามแต่ละ SKU:

| บริการ | โควตาฟรีต่อเดือน | หมายเหตุ |
| --- | --- | --- |
| Maps Embed API (iframe) | ไม่จำกัด | ฟรีจริง แต่ยังต้องมี API key |
| Maps JavaScript (dynamic map) | ~10,000 loads | เกินแล้ว ~$7 ต่อ 1,000 |
| Places Nearby/Text Search Pro | ~5,000 ครั้ง | ได้ rating และเวลาเปิดปิด แต่ **ไม่มีเมนู** |
| Routes Matrix Essentials | ~10,000 ครั้ง | ใช้คำนวณระยะเดิน |

ข้อจำกัด:

- ต้องผูกบัตรเครดิตกับ billing account ทุกกรณี
- เงื่อนไขของ Places **ห้ามเก็บข้อมูลร้านไว้ถาวร** (เก็บได้แค่ place_id) จึงต้องเรียก API ซ้ำ
- การ scrape หน้า Google Maps ผิดเงื่อนไขการใช้งาน **ไม่ทำ**

**ข้อแนะนำ:** ใช้ OSM สำหรับข้อมูลร้าน, MapLibre + CARTO Dark Matter tiles สำหรับแผนที่ (ฟรี เข้ากับ dark mode แค่ใส่ attribution) และใช้ deep link ไป Google Maps
ถ้าอยากได้ rating หรือรูปจาก Google ค่อยเพิ่ม Places API เป็นเฟสเสริม โดยตั้ง budget alert ไว้ $1

## 5. ระบบ weight และการสุ่ม

```
weightร้าน   = baseWeight (ค่าเริ่มต้น 1, ปรับได้ 0–5)
             × memberMultiplier
memberMultiplier = max(0.1, 1 + 0.25 × ผลรวมโหวตของสมาชิก)  // แต่ละคนโหวตได้ -1, 0, +1 ต่อร้าน
weightเป็น 0      = ตัดร้านออกจากการสุ่ม
โอกาส (%)       = weight / ผลรวม weight ของร้านที่ผ่านตัวกรอง
```

- เมนูใช้สูตรเดียวกันภายในร้าน
- ตัวกรองต่อจาก weight: ระยะ (1 กม. หรือ 500 ม.), ประเภทอาหาร, "เปิดตอนนี้" (เฉพาะร้านที่มีเวลาเปิดปิด), ไม่ซ้ำกับร้านที่กินเมื่อ N วันก่อน (ไม่บังคับ)
- ใช้ `crypto.getRandomValues` สำหรับการสุ่ม และเก็บประวัติผลสุ่มไว้
- เขียน unit test เพื่อพิสูจน์ว่าสุ่ม 10,000 ครั้งแล้วสัดส่วนที่ได้ใกล้เคียงกับ % ที่ตั้งไว้

## 6. Mode member

1. กด "สร้างห้อง" จะได้ลิงก์ `/room/ABCD` ไว้แชร์ใน LINE
2. สมาชิกใส่ชื่อเล่น (ไม่ต้องสมัครสมาชิก) แล้วโหวต +/- ร้านในรายการ
3. ตาราง % อัปเดตสดเมื่อมีคนโหวต
4. เจ้าของห้องกด "จับสลาก" แล้วทุกคนเห็นผลพร้อมกัน จากนั้นสุ่มเมนูต่อ

ตารางในฐานข้อมูล: `rooms(id, code, created_at, lazy_mode)`, `members(id, room_id, nickname)`, `votes(room_id, member_id, restaurant_id, value)`, `draws(room_id, restaurant_id, menu_id, at)`

## 7. การออกแบบ (ใช้ unslop, dark mode, สไตล์เว็บแข่งขัน)

**ติดตั้ง skill:** คัดลอก `skills/unslop` จาก repo `heydamir/unslop` ไปไว้ที่ `.claude/skills/unslop` ในโปรเจกต์ แล้วสั่ง `/unslop` หลังจากหน้าแรกใช้งานได้แล้ว
(License CC BY 4.0 ต้องใส่เครดิต `unslop by @heydamir`)

**Direction (5 บรรทัดตามที่ unslop กำหนด)**

- **Product:** สุ่มร้านข้าวกลางวันให้ทีมจันวาณิชย์ จากร้านที่เดินไปได้รอบสีลม
- **Character:** ลุ้น, ฉับไว, เป็นกันเอง
- **World:** กระดานราคาต่อรองของสนามแข่ง ผสมป้ายเมนูร้านข้าวแกงตามซอยสีลม หลังเลิกงานตอนค่ำ
- **Moments:**
  1. **กระดานโอกาส (odds board)** เป็นตารางร้านพร้อม % และแถบความยาวตาม weight ตัวเลข mono เรียงขวา และเลขจะ tween เมื่อมีคนโหวต
  2. **การ์ดผู้ชนะ** แสดงชื่อร้าน, เมนู, ระยะเดิน, แผนที่ dark ที่มีเส้นทางเดิน และปุ่มเปิด Google Maps
- **Signature:** เลขประจำร้านแบบ "เบอร์ม้า" (#01–#237) ในกล่อง mono ทุกที่ที่ร้านปรากฏ

**ความรู้สึกแบบเว็บแข่งขัน ทำโดยไม่ให้กลายเป็น slop:** ใช้ leaderboard/odds board, เบอร์ประจำร้าน, ผลจับสลากที่ทุกคนเห็นพร้อมกัน และ "สถิติแชมป์" (ร้านที่ชนะบ่อยประจำสัปดาห์)
**ไม่ใช้** gradient ม่วง, glow, neon, emoji หรือวงล้อสีรุ้ง แอนิเมชันตอนสุ่มให้เป็นการไล่แถวไฮไลต์บนกระดานแล้วค่อยๆ ช้าลง ใช้ easing เดียวกันทั้งหน้า

**Tokens (dark, graphite ramp ของ unslop)**

- bg `#141415`, card `#19191b`, raised `#232325`, hairline = text 8%
- text `#ededed` / `#a1a1a6` / `#85858b`
- accent สีเดียวคือ **ส้มถ่านไฟ (ember) `#f0883e`** (ร้อน กลิ่นอาหาร) ใช้กับปุ่มจับสลาก ร้านที่ชนะ และตัวเลข % สูงสุด
- spacing grid 4px, radius: control 8, card 14, panel 18

## 8. โครงหน้าเว็บ

| Route | เนื้อหา |
| --- | --- |
| `/` | ซ้ายเป็น odds board พร้อมตัวกรอง (toggle ขี้เกียจเดิน, ประเภทอาหาร) ขวาเป็นปุ่มจับสลาก การ์ดผู้ชนะ และแผนที่ |
| `/r/[id]` | รายละเอียดร้าน เมนูพร้อม weight ปรับ %, เพิ่มเมนู, ลิงก์ Google Maps |
| `/room/[code]` | Mode member: รายชื่อสมาชิก, โหวต +/-, กระดานสด, ผลจับสลาก |
| `/history` | ประวัติผลสุ่มและสถิติแชมป์ |

บนมือถือ (คนจะเปิดจากมือถือตอนเที่ยงเป็นหลัก) เรียงเป็นปุ่มจับสลาก → ผู้ชนะ → กระดาน
